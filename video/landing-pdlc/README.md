# Как было → как стало

Ролик главной: девять сцен PDLC, 1920×1080, Allan (`eleven_v4`, скорость 0,85),
вшитые субтитры и отдельная VTT-дорожка. Исходный сценарий сохранён целиком
в [storyboard.md](storyboard.md). Последняя поправка 13:55 задаёт короткую речь
сцены 4: два комментария и одно одобрение владельца продукта. Она имеет приоритет
над длинной репликой в исходной таблице. Длительность по итоговому голосу — 81,1 с.

```text
storyboard.md → voice → assets/vo-v3 (исходный голос)
                       ↓ build-vo (паузы и выравнивание)
                 assets/vo + scenes.json
                       ├→ build-scenes → compositions → build-index → index.html
                       └→ build-captions → VTT / SRT / главы / расшифровка
```

Визуальные образцы: узлы и подписи `block-sdd/scene-0m`, карточки файла и роли
`block-r2/scene-02`, галочки и переход к следующему действию `block-sdd/scene-06`.
Четыре карточки глав лежат поверх первых двух секунд сцен 3, 4, 7, 8;
длительность фильма они не увеличивают. Общие инструменты и CSS синхронизируются
из `video/_shared`; `kit.js` взят из `block-sdd`, `sketches.js` содержит только
движения новой полосы PDLC. Фон без декоративных частиц и кругов.

Из каталога HyperFrames проверены `data-chart` и `chart-story`. Новый график
не нужен: поправка сценария 13:50 требует существующие бейджи курса.

## Пересборка

Из `film/`, без повторного платного синтеза:

```sh
node tools/build-vo.mjs
node tools/build-scenes.ts
node tools/sync-dur.mjs
node tools/build-index.mjs
node tools/build-captions.mjs
npm run check
```

При изменении речи заново озвучить только изменённые блоки, затем пересобрать:

```sh
ELEVENLABS_PREPROXY=socks5h://127.0.0.1:1280 node tools/voice.mjs assets/vo-v3 7,8
```

Из корня репозитория: `node video/_shared/sync.mjs --check`, `npm test`,
`npm run typecheck`. Медиа: из `video/landing-pdlc` выполнить
`shasum -a 256 -c MEDIA.sha256`.

## Отдельное окно рендера

MP4 в этом пакете не создаётся и не публикуется. В выданном окне из `film/`:

```sh
npm run render
```

Команда закреплена на `hyperframes@0.8.164`, проверенном по npm 16.10.2026.
После рендера нужны просмотр движения и стыков, нормализация громкости для выпуска,
сверка конечной длительности и хеш MP4. Измерение текущего голоса: −19,8 LUFS,
true peak −2,3 dBFS. Произношение по брифу не перепроверяется.
Рендеры и временные результаты исключены из Git локальным `film/.gitignore`.
