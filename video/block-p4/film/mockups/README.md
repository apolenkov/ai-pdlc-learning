# Изолированные макеты p4

Это исходники макетов для проверки структуры кадров, не производственные композиции. Секунды условные: сцена 03 намеренно содержит последовательные подшаги шести смысловых шагов; сцена 05 — восемь состояний. Ни длительности, ни их границы не переносить в фильм или alignment. Озвучки нет, S.t и искусственного выравнивания нет. Контент и размеры унаследованы от «Студии».

## Сборка и source gate

Из корня worktree:

```sh
node --experimental-strip-types video/block-p4/film/mockups/build.ts
node --experimental-strip-types video/block-p4/film/mockups/check-source.ts
node --experimental-strip-types video/block-p4/film/mockups/prepare-review.ts <OUT-вне-worktree>
```

Генератор пишет только внутри mockups. Поля времени и midpoint — [snapshot-times.json](snapshot-times.json). В каждом состоянии чтение ≥слов/3+1 с после полного появления; новые UI-пары появляются перед командой. Это не обещание вместить команды в будущую VO. Альтернатива — компактный маршрут со ссылкой на гайд из [брифа сцены 03](../briefs/scene-03.md).

## Самодостаточный проект для HyperFrames

Git не хранит копии kit, шрифтов или GSAP. Сгенерированные HTML ссылаются на project-local kit/assets; до prepare-review они — переносимые исходники, не готовые к запуску проекты. prepare-review копирует точные локальные ресурсы в OUT/projects/scene03, scene05, title05 и пишет mockup-source-proof.json с SHA каждой исходной и целевой копии. Исходники ресурсов в Git не дублируются. У title05 копируется фактическая production composition scene-t5.html; текст вручную не воспроизводится. KIT_SCENES t5 берётся из scenes.json. Длительность 2 с не меняется.

После координации LANE из каждого подготовленного проекта запускать check и snapshot на пине 0.8.164. Выполненный run2: у всех трёх проектов 0 ошибок, контраст 82/82, 56/56 и 65/65 AA; у сцен 18 и 9 advisory lint warnings о плотности/nested-structure. Сохранены 21 + 12 + 6 полных PNG и контактные листы. Ошибки первого запуска с parent traversal сохранены как run1 (браузер не запускался). Source gate сам по себе визуальный PASS не означает.
