# Бриф сцены 03 «Комментарии, одобрение и передача» (оценка 68 с, главная)

Приёмы-образцы: схема принятия kit + учебный макет запроса на слияние как r2-06 —
нить комментариев + одна кнопка «Одобрить» с чипом «владелец продукта»
(одобрение одно, живых систем нет, имена вымышлены).

Кадр: схема «ветка → запрос на слияние → два комментария → одно одобрение →
запись передачи (кто принял в работу — аналитик / где решение — ссылка на запрос / ревизия)»;
макет запроса целиком. Копий записи нет — документ один.

Якоря S.t (после озвучки): «отдельной ветке», «запрос на слияние», «одно одобрение», «Копий записи нет».
Термины в речи: ветка (отдельная копия документа для правок);
запрос на слияние (просьба принять ветку в общую версию);
ревизия (хеш коммита или тег).
