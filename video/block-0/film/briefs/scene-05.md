# Сцена 05 — «Проверяем» (речь ≈34 с); текст: блок 5
Зритель должен понять: ревью — это чтение требований коллегами; оно находит то, что автор не видит, и замечание попадает в документ.
Смотреть первым: скетч `team-done` (автор и двое проверяющих) и список из четырёх сценариев с пустым местом.
Было → стало: четыре сценария → вопрос проверяющего «после успешного расчёта ввести неверный срок?» → пятый сценарий добавлен в документ (зелёная строка), «в переписке» не остаётся.
Ритм: «техлид… и другой аналитик» → две метки ролей у скетча (термин «техлид — ведущий разработчик команды» одной подписью, не второй); «В черновике четыре сценария» → список из 4 строк; «среди них нет случая» → подсветка пустого места акцентом; «Проверяющий спрашивает именно об этом» → pop реплики; «добавляет пятый» → строка 5 вписывается зелёным; «Теперь требования можно принимать» — итог.
Не делать: путать ревью и приёмку (приёмка — сцена 06).
Проверка кадров: 2, 8, 14, 20, 26, 32 с.
