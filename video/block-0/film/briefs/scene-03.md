# Сцена 03 — «Записываем замысел» (речь ≈47 с); текст: блок 3
Зритель должен понять: замысел — короткий документ из пяти частей (проблема, результат, границы, признаки успеха, открытые вопросы), источник в шапке; смысл подтверждает инициатор, одобряет владелец продукта.
Смотреть первым: документ intent.md в окне редактора kit: шапка с источником, затем пять частей по очереди.
Ритм: каждая часть появляется на слове своего названия («Проблема:», «Результат:», «Границы:», «Признак успеха:», «Открытый вопрос:»), предыдущая приглушается до `--k-text-2`, но остаётся читаемой; «Источник — в шапке» подсвечивает строку шапки; «Инициатор подтверждает… владелец продукта принимает» — две метки-роли с разными вопросами/галочками; последняя фраза «осталось описать «как»» ведёт к следующей части.
Состав частей и подписи — как на странице guides/block-0 (шаг 4): «Проблема, Результат, Границы, Признаки успеха, Открытые вопросы»; шапка: автор, владелец решения, состояние, источник.
Не делать: семь разделов старого шаблона; «владелец продукта».
Проверка кадров: 3, 10, 16, 22, 28, 34, 40, 46 с.
