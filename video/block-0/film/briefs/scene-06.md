# Сцена 06 — «Одобряем и передаём» (31,5 с, речь 29,5); текст: блок 6 (v3)
Зритель должен понять: версию одобряет только владелец продукта — сверяет её с замыслом; аналитик и техлид комментируют, архитектор подключается по признакам; принятая версия — результат этапа анализа, передаётся по ссылке с открытыми вопросами (правило 590, B1-V9).
Смотреть первым: плитка «Версия требований · одобряет владелец продукта» с одним кружком-галочкой, затем её замена карточкой «Принятая версия».
Проблема → цель: «Версия требований» (пустой кружок) → кружок зеленеет у владельца → «Принятая версия» (зелёная) с чипами «ссылка» и «открытые вопросы».
Ритм: «версию» → плитка и четыре пустые карточки; «одобряет» → кружок и подпись «одобряет владелец продукта»; «владелец продукта… сверяет… «это то, что я просил»» → карточка + цитата, кружок зеленеет; «Аналитик», «Техлид» → карточки и пометка «комментирует» (без галочек); «Архитектора… данные, интеграции, безопасность, скорость» → карточка с пунктом по слову (пунктирная, по признакам); «Порядок одобрения определяет команда» → короткая плашка; «Принятая версия» → плитка заменена результатом; «результат этапа анализа», «по ссылке», «открытыми вопросами» → подпись и два чипа.
Скетч/схема/карточка: kit.aside (карточки ролей, результат), без скетча.
Не делать: определение «техлид — ведущий разработчик» (в v3 диктор даёт его в блоке 5); фразу «чтобы её всегда можно было найти» (убрана из речи).
Проверка кадров: 2,6; 7; 12; 16,5; 23,5; 31 с.
