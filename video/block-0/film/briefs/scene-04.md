# Сцена 04 — «Описываем поведение» (28,6 с, речь 26,5 с); текст: блок 4 раскадровки v3
Зритель должен понять: требования — ожидаемое поведение; сценарии — примеры «что вводим — что получаем» (показаны два из четырёх); «сделать понятнее» — пожелание, а не правило; хватит ли сценариев, решат коллеги.
Смотреть первым: две верхние карточки «Требования → Сценарии», затем две строки сценариев (верный срок, неверный срок).
Ритм: «ожидаемое» → подпись требований, «требования» → название; «Конкретные» → карточка сценариев и стрелка, ««что» / «сценариями» → подпись и название; «два из четырёх» → плашка из четырёх квадратов; «Если срок верный» → строка 1, «калькулятор показывает» → результат, «рассчитанный платёж» → подпись; «Если неверный» → строка 2, «сообщение у» → сообщение у поля, «вместо суммы» → прочерк; «Просто» → пожелание красной рамкой; «Хватит» → вопрос, «решат» → «решат коллеги». Хвост ≥ 1,5 с.
Скетч/схема/карточка: схематичные карточки калькулятора (kit.aside), скетчи не нужны.
Не делать: тройной повтор одного смысла в кадре; текст мельче 28 px; контент ниже y 865.
Проверка кадров: 3, 7, 10, 14, 18, 22, 25, 27 с.
