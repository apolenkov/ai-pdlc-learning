# Сцена 00 — «Как было» (дл. 38 с, речь 36,5 с); текст: блок 0 в `../../storyboard.md`
Зритель должен понять: просили одно, сделали другое — потому что смысл запроса терялся в инструментах, а цена — неверная спецификация.
Смотреть первым: «одно / другое» крупно (крючок), затем скетч ch-gitlab.
Было → стало: эта сцена — только «было»; каждая проблема получает в сцене 0b зеркальный кадр на той же раскладке (скетч слева, карточка-последствие справа), поэтому раскладку держать одинаковой.
Ритм (всё через `S.t("фраза")`): «Просили одно, а сделали другое» → две карточки + скетч `ch-gitlab` (рисуется 2,4 с); «знакомо?» → pop; «Требования жили в Confluence, Word и Google Docs» → скетч `ch-computer` + три плитки названий; «решения терялись в чате и почте» → `was-chat` (новый); «без единого шаблона… разработчик додумывал» → карточка-последствие; «без обязательной проверки ошибка доходила до разработки» → карточка; «документы лежали отдельно от кода» → `was-apart` (новый, стена между людьми); «решения восстанавливать по памяти» → `thinking` с пустым облаком; финал — «спецификация могла получиться неверной» тёплым акцентом (--k-accent-soft).
Скетч показывает действие, карточка рядом — результат; одна надпись не повторяется в обоих.
Не делать: одинаковые fade-in у всех карточек; текст по центру без скетча/плитки; гасить элемент, пока слово звучит.
Проверка кадров: 1, 6, 12, 18, 24, 30, 36 с.
