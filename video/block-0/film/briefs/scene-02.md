# Сцена 02 — «Уточняем запрос» (31,8 с, речь 29,8 с); текст: блок 2 раскадровки v3
Зритель должен понять: ответы берут у инициатора, записывают рядом с запросом с указанием источника; нет ответа — вопрос остаётся открытым, предположение его не заменяет.
Смотреть первым: две карточки участников (инициатор слева, аналитик справа), затем вопросы справа и ответы слева.
Ритм: «инициатора» → имя на карточке; «Аналитик» → карточка аналитика; «Что показать» / «Меняется ли» → два вопроса справа; «рядом с неверным» / «прежний платёж» / «формулу не трогаем» → три ответа слева; «Ответ записываем» → плитка «запрос» с линией от ответов; «указываем» → «откуда взят: ответ инициатора»; «Если ответа» → пунктирная пустая ячейка справа, «открытый вопрос» → её название; «предположение» → карточка «Предположение не заменяет ответ» под ячейкой. Хвост ≥ 1,5 с.
Скетч/схема/карточка: карточки kit.aside, плитка kit.path; скетчи не нужны.
Не делать: определение «вопрос, на который ещё нет решения» и строку «Ответы и открытые вопросы → замысел» (в речи v3 их нет); текст мельче 28 px.
Проверка кадров: 3, 8, 13, 17, 21, 25, 28, 30 с.
