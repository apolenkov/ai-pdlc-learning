# Сцена 00 — Как было (28.3 с, речь 26.7); текст: блок 00 в `../../storyboard.md`
Зритель должен понять: у двоих одна работа и две версии одного документа — какая последняя, что и почему изменилось, неизвестно.
Смотреть первым: вопрос «Какая последняя?» крупно, затем скетч `was-copies` (НОВЫЙ, линейный, без лиц: два стола, две копии листа с пометками «финал» / «финал два» / «финал после правок»).
Было → стало: только «было»: тёплое, тесное (акцент-мягкий), три имени файла стопкой, часть строк зачёркнута/теряется.
Ритм: «Вдвоём правили» → скетч; «Какая последняя?» → вопрос-акцент; «Что в ней изменилось и почему?» → второй вопрос под первым; «Покажем…» → строка-обещание; «финал», «финал два», «финал после правок» → три плитки-имени файла по слову; «прежний текст пропадал» → плитка гаснет; «Правки сводили вручную, и часть терялась» → итоговая строка.
Скетч/схема/карточка: новый `was-copies` (сделать по образцу assets/sketches/*.svg, `tools/build-sketches.mjs`), плитки `Kit.path`/`Kit.aside`.
Не делать: текст по центру без опоры; одинаковый fade всех плиток; лица.
Проверка кадров: 1, 6, 12, 18, 24 с.
