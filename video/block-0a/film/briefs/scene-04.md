# Сцена 04 — Меняем документ и сравниваем (18.1 с, речь 16.1); текст: блок 04 в `../../storyboard.md`
Зритель должен понять: второй Commit добавляет версию, первая остаётся; сравнение показывает «было → стало», добавленная строка выделена.
Смотреть первым: добавленная строка в редакторе, затем диф слева/справа и две записи в графе.
Было → стало: диф «было | стало» с зелёной добавленной строкой (`scr.areas` или `ed.addLine`).
Ритм: «Допишите в границы одно правило» → запись scene-04-diff (печать строки); «снова нажмите Commit» → запись scene-04-graph (Commit); «Появилась версия два, а версия один осталась» → две точки в `Kit.gitGraph` (по слову «два», «один»); «Откройте сравнение: слева было, справа стало» → подписи «было» / «стало» над колонками; «Вернуться… в любой момент» → итоговая строка.
Скетч/схема/карточка: записи scene-04-*; `Kit.gitGraph`.
Не делать: показывать git diff в терминале.
Проверка кадров: 2, 6, 10, 14 с.
