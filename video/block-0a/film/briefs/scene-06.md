# Сцена 06 — Ветка для другого варианта (16.3 с, речь 14.2); текст: блок 06 в `../../storyboard.md`
Зритель должен понять: ветка — отдельная линия истории; main не меняется, пока правим в ветке.
Смотреть первым: линия main и ответвление (Kit.gitGraph), параллельно запись создания ветки.
Ритм: «Хотите проверить другую границу…?» → вопрос-карточка; «Создайте ветку — отдельную линию истории» → запись scene-06-branch (клик по main в строке состояния → Create new branch → имя); «Основная ветка называется main, и она не меняется» → линия main подсвечена, замок/неподвижность; «Правьте… и сохраняйте версии как раньше» → точка в ветке, запись scene-06-switch (переключение показывает прежний пункт на main).
Скетч/схема/карточка: `Kit.gitGraph` (lanes main и ветка), записи scene-06-*.
Не делать: ветку показывать как копию папки.
Проверка кадров: 2, 5, 8, 11, 14 с.
