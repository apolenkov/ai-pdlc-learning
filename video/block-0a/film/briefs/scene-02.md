# Сцена 02 — Копии против истории (17.9 с, речь 15.8); текст: блок 02 в `../../storyboard.md`
Зритель должен понять: две копии — разницу ищешь глазами, причины нет; Git хранит историю ОДНОГО файла с автором, временем и причиной.
Смотреть первым: две копии рядом (запись scene-02-copies / compare), затем «история одного файла» — вертикальная линия версий с автором, временем, причиной.
Было → стало: «было» — две копии intent-1.md / intent-2.md (тёплые, без причины); «стало» — один файл и список версий (`Kit.gitGraph` или три карточки версий, спокойный зелёный).
Ритм: «Две копии файла лежат рядом» → запись copies; «разницу приходится искать глазами» → подсветка расхождения (не больше одной); «причину никто не записал» → пустая подпись-вопрос; «Git хранит не набор копий, а историю одного файла» → переход к стало; «автор, время и причина» → три метки по слову.
Скетч/схема/карточка: записи scene-02-*; `Kit.gitGraph`/`Kit.aside`.
Не делать: два заголовка с одним смыслом; показывать команды.
Проверка кадров: 1, 4, 8, 12, 15 с.
