# Сцена 0b — Как меняется работа (40.8 с, речь 39.2); текст: блок 0b в `../../storyboard.md`
Зритель должен понять: мы пишем в Markdown, версии хранит Git, место хранения — репозиторий в GitLab; модель правит файлы, а Git показывает, что она поменяла; и что именно зритель сейчас сделает.
Смотреть первым: цепочка из трёх плиток «Markdown → Git → GitLab» (появляются по словам), затем строка «вы сделаете» из четырёх действий.
Было → стало: зеркало к блоку 0: спокойное (зелёный `--k-ok`, одна линия) вместо хаоса копий.
Ритм: «Поэтому документы ведём иначе» → переход blur/scale от «было»; «Markdown — простой текст с разметкой» → плитка 1 + определение (одно определение — одна надпись); «Git — программа…» → плитка 2 + определение; «репозиторий… GitLab» → плитка 3; «модель читает и правит… откатить» → пара «модель правит → Git показывает → откат» (стрелки kit); «Вот что вы сделаете» → четыре карточки `Kit.goals`-стиля: «замысел», «история», «отдельный вариант», «правка коллегам».
Скетч/схема/карточка: `Kit.path`, `Kit.goals`, иконки `file commit branch cloud`.
Не делать: повторять «документы как код» из ролика 1; шкалу зрелости.
Проверка кадров: 1, 8, 16, 24, 32, 38 с.
