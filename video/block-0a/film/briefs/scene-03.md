# Сцена 03 — Включаем Git и сохраняем первую версию (20.7 с, речь 18.7); текст: блок 03 в `../../storyboard.md`
Зритель должен понять: Initialize Repository включает Git в папке; сохранить файл и записать версию (Commit) — разные действия; причину версии пишем сами.
Смотреть первым: кнопка Initialize Repository в Source Control (камера на неё), затем поле сообщения и Commit.
Ритм: «нажмите Initialize Repository» → запись scene-03-init, курсор 1 с до клика; «Появится служебная история, пока пустая» → карточка «.git — история, пока пустая»; «Сохранить файл и записать версию — разные действия» → пара «Cmd+S ≠ Commit»; «Запись версии называется Commit» → запись scene-03-commit (Stage, сообщение, Commit); «Первая версия замысла» → подпись сообщения; «Теперь версия в истории» → результат зелёным (одна запись).
Скетч/схема/карточка: записи scene-03-init, scene-03-commit; `Kit.aside`, `Kit.goals` не нужны.
Не делать: терминал и git config в кадре (запись обрезана); пересказ текста страницы.
Проверка кадров: 2, 6, 10, 14, 18 с.
