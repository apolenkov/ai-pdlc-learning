# Сцена 01 — Пишем замысел в Markdown (21.3 с, речь 19.3); текст: блок 01 в `../../storyboard.md`
Зритель должен понять: замысел — файл intent.md; # и - — это разметка; предпросмотр показывает тот же текст оформленным.
Смотреть первым: запись VS Code (создание файла), затем предпросмотр слева исходник / справа вид читателя.
Ритм: «Создайте файл intent.md» → запись scene-01-create (клик New File → вставка → сохранение); «Заголовок начинается с решётки, пункты списка — с дефиса» → подписи-знаки `#` и `-` у строк (aside справа, камера на строки); «Откройте предпросмотр» → запись scene-01-preview; «Один файл, два вида» → итоговая строка/пара «исходник | вид читателя» (`scr.areas`).
Скетч/схема/карточка: записи пилота + `Kit.screen`, `Kit.keycard` для Cmd+K V если успевает.
Не делать: пересказывать текст страницы; подписи мельче 28 px.
Проверка кадров: 2, 6, 10, 14, 18 с.
