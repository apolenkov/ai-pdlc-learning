# Бриф сцены 01 «Что такое план изменений» (оценка 55 с)

Приём-образец: карточка-шаблон kit (5 полей строки) + схема-стрелка (как i1-01).

Кадр: карточка строки плана (что меняется / результат / кто делает / зависимость / готовность),
схема «строка плана → отдельное изменение анализа», пометка «дат нет».

Якоря S.t (после озвучки): «пять полей», «Календарных обещаний», «Тяга записать дату».
Термины в речи: продуктовое изменение (что меняется для человека);
ревизия (подпись версии принятой записи); отдельное изменение анализа (OpenSpec).
