# Как участвовать

Правки принимаются через pull request. Вносить их может любой, кто видит проект.

## Порядок

1. Создайте fork проекта и ветку от `main` (`course/<кратко-что-меняете>`).
2. Установите окружение: Node.js из `.nvmrc`, затем `npm ci`.
3. Внесите правку в исходники (`docs/pages/sdlc-development/`, см. структуру в [README.md](README.md)).
4. Проверьте: `npm test`, `npm run typecheck`, `npm run build:site`, затем `npm run preview` и откройте изменённые страницы.
5. Закоммитьте по Conventional Commits, например `docs(guides): добавить проверку результата в С2`.
   Хуки `lefthook` проверяют типы, сообщение и тесты перед push; обходить их нельзя.
   Хук `corp-guard` сверяет правки со стоп-листом сопровождающего, которого в репозитории нет.
   Без стоп-листа задайте `export CORP_GUARD_STOPLIST=none`: хук напишет, что пропущен, а правку
   проверит сопровождающий.
6. Откройте pull request в `main`. В описании: что изменилось, на какую страницу смотреть, как проверили.

## Что принимается

- Исправления текстов, шагов, примеров и ошибок в гайдах; новые учебные материалы по теме курса.
- Исправления сборки и проверок.

## Что не принимается

- Пароли, токены, персональные данные, внутренние выгрузки, материалы закрытых проектов (см. [docs/BOUNDARIES.md](docs/BOUNDARIES.md)).
- Снимки экрана с реальными именами, учётными записями и адресами сессий.
- Изменения лицензии и авторских условий: их определяет владелец.
