# Доменный словарь

| Термин | Определение |
| --- | --- |
| Сумма кредита | Начальная сумма, участвующая в расчёте |
| Годовая ставка | Номинальная процентная ставка за год |
| Срок | Количество ежемесячных платежей |
| Ежемесячный платёж | Округлённый аннуитетный платёж для заданных входов |

Сервисные технические термины остаются в сервисных репозиториях и не
переносятся в продуктовый контекст.
