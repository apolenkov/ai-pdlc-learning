# Учебные запросы кредитного калькулятора

Материалы по учебному кредитному калькулятору. На каждый самостоятельный запрос
к продукту готовят свою запись намерения, например `intents/clear-calculation-result.md`. В курсе «Намерение и план»
запись ведут по шаблону из списка ниже. В курсе анализа шаги 1–3 уточняют первый запрос,
а шаг 5 «Контекст продукта» берёт второй: лимит суммы.

- [Исходное обращение и ответы](request-and-answers.md) — материал для собственной формулировки.
- [Шаблон intent.md курса «Намерение и план»](../intent-plan/intent-template.md)
- [Короткий шаблон курса анализа](intent-template.md)
- [Сильный образец](../intent-plan/strong-intent.md) — образец записи намерения курса «Намерение и план».
- [Разобранный пример курса анализа](intents/clear-calculation-result.md) — как уточняют замысел на шагах 1–3 курса анализа.
- [Лимит суммы из системы банка](intent-2-credit-limit.md) — следующий запрос для шага 5 курса анализа.

В папке `intents/` по одной записи на самостоятельный запрос. Новый урок уточняет
ту же запись: смысл согласуют с инициатором и владельцем решения, прежние версии
видны в истории Git.
