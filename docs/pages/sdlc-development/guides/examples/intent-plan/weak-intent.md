# Слабая запись намерения: кнопка «Очистить»

Слабая запись: в проблеме уже стоит готовое решение, эффект не назван числом,
границ нет, вопросы без адресатов. Такой документ рецензент возвращает владельцу продукта.
Люди вымышлены. Исходное обращение:
[обращение и ответы](../credit-calculator-intents/request-and-answers.md).

Инициатор: представитель кредитного отдела
Владелец решения: владелец продукта
Помощник (аналитик): не определён
Состояние: черновик
Источник: письмо владельца продукта

## Проблема

Нужна кнопка «Очистить» в калькуляторе.

## Результат

Клиенты видят кнопку «Очистить».

## Признаки успеха

Клиентам нравится кнопка. Точный эффект покажем позже.

## Границы

Границы уточним в работе.
