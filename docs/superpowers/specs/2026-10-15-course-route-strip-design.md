# Линия маршрута курса и «конфетка» выпуска TASK-554 · дизайн

Дата: 15.10.2026. Автор: 014 (customdev-unify). Решения: владелец через координатора 008

## Зачем

Курс длинный (12 гайдов, ≈ 52 мин роликов). Обучаемый должен в любой момент видеть, где он, что пройдено и сколько
осталось, — линия П → С → Д из украшения становится индикатором. Тон владельца: «люди должны увидеть конфетку и хотеть
кликать» — живо, но спокойно, в стиле CustomDev (бумага, зелёный, тонкие линии), без отвлечения от чтения.

## Цели

1. **C. Липкая полоса маршрута** под общим меню на карте (`guides/index.html`) и на каждой странице гайда
   (`body[data-stage]`).
2. **D. Шестерёнки**: две маленькие сцепленные шестерёнки в полосе; поворот — от прокрутки страницы.
3. **F2. Превью ролика** при наведении на карточку гайда на карте + значок длительности.
4. **F3. Самопроверка**: пункты финальной самопроверки отмечаются; когда отмечены все — короткий «щелчок» успеха,
   точка шага на полосе становится пройденной; в конце Д1 — карточка «Маршрут пройден».
5. **A.** Ролик «Как пользоваться картой» — сверху блока «Как пользоваться картой», карточки ниже.
6. **B.** Буквы на линии маршрута подписаны словами: «Подготовка», «Практика», «Разработка».
7. **Дефект «С4·в»**: код в круге карты вылезает из круга — блокирует визуальный PASS.
8. Мелкое с того же кадра: на `course/guides/` убрать полосу фона другого оттенка под меню; подпись над H1
   («SDLC · практический маршрут аналитика») — как на главной CustomDev: жирная, зелёная.

## Не цели

- Таймер чтения (E) — отдельная задача 008.
- Серверное хранение прогресса, аккаунты, аналитика: ничего не отправляется с машины читателя.
- Новые ролики-превью: превью берёт кусок существующего mp4.
- Пункты Fable 1–8, меню, `<title>`, ссылки «назад» (013).

## Анти-цели (провал, даже если «работает»)

- Полоса теснит чтение: выше 56 px на десктопе / 44 px на 390, перекрывает якоря (`scroll-margin-top`), дёргается.
- Движение без смысла или при `prefers-reduced-motion: reduce` — там всё статично.
- Прогресс «врёт»: пройденным помечено то, что читатель не видел и не отмечал, кроме правила «всё до текущего шага».
- Превью грузит ролики без наведения (трафик) или играет со звуком.
- Две линии маршрута на одном экране карты (липкая полоса + полоса в блоке) читаются как два разных индикатора.

## Решения владельца/008 (как приняты)

- Слова групп: «Подготовка П1–П3 · Практика С1–С4 · Разработка Д1»; у каждой точки — код шага.
- Пройдено = все шаги маршрута до текущего + шаги, у которых читатель отметил всю самопроверку (только `localStorage`,
  кнопка «Сбросить отметки»).
- Время — из длительностей роликов (манифесты, как «Ролик m:ss» на карте): «пройдено ≈ N мин · осталось ≈ M мин роликов».
  Итоговая карточка: «≈ 52 мин роликов» (сумма маршрута).
- 390 px: компактная полоса — код, этап, «осталось ≈ N мин»; без превью по наведению; шестерёнки — если не теснят текст.
- Ролик в блоке — сверху (A), подписи словами (B).

## Устройство

### Данные (на этапе сборки)

`course-names.json` уже даёт порядок `route[]` (id, code, group), `branches[]` (С4а/С4б от `3-star`), `groups`.
Длительности — `filmDuration()` из `scripts/course-map.ts` (манифесты в Git). Сборка пишет в каждую страницу курса один
JSON `<script type="application/json" id="course-route">` (шаги: id, code, group, title, href, seconds; ветки) — тот же,
что генерирует карта; при отсутствии ролика `seconds: null` и шаг в сумме не участвует.

### Полоса (C)

- Монтируется рантаймом из `course-motion.ts` сразу под `[data-global-nav]`, `position: sticky; top: var(--site-nav-reserve)`;
  `--site-nav-reserve` растёт на высоту полосы, чтобы якоря не уходили под неё.
- Текущий шаг: `body[data-stage]`; для С4а/С4б текущая — точка ветки. На карте текущего нет: все точки «будущие»,
  справа «Начните с П1 · ≈ 52 мин роликов».
- Десктоп: три подписанных сегмента (слово группы + диапазон кодов) с точками; под точкой код (П1…Д1; С4а/С4б —
  маленькая развилка после С4). Точка — ссылка на гайд (`title` = название гайда, видимая подсказка при наведении/фокусе).
  Состояния: пройдена (зелёная заливка), текущая (крупнее, кольцо, `aria-current="step"`), впереди (контур).
  Справа текстом: «Практика · С2» и «пройдено ≈ 21 мин · осталось ≈ 31 мин роликов».
- 390: одна строка — код и этап слева, «осталось ≈ N мин» справа, тонкая шкала прогресса снизу; точки скрыты.
- Доступность: `<nav aria-label="Маршрут курса">`, список ссылок, текст состояния — для читалки («пройдено», «вы здесь»).

### Шестерёнки (D)

Inline SVG (две шестерёнки 18 и 12 px, ≤ 2 КБ) у левого края полосы. Угол = прокрутка × k (большая по часовой,
малая против с передаточным числом), обновление в `requestAnimationFrame` только при прокрутке, `transform: rotate`.
`prefers-reduced-motion: reduce` — не подписываемся на прокрутку. Весь новый JS+CSS ≤ 50 КБ (бюджет анимаций).

### Превью ролика (F2)

На карточке гайда в карте — значок «▶ m:ss» в углу. При наведении (только `(hover: hover)` и без reduced-motion,
задержка 350 мс): над карточкой появляется кадр 16:9 с `<video muted playsinline preload="none">` того же mp4,
воспроизводится отрезок 4 с из середины ролика по кругу; уход курсора — пауза и `src` сбрасывается. Без mp4
(сборка без видео) — превью нет. Клик по значку ведёт к ролику гайда (`#lesson-video`).

### Самопроверка и «щелчок» (F3)

- Пункты «Финальной самопроверки» (`ul.check`) становятся переключателями (`button role="checkbox" aria-checked`),
  вид прежний (квадрат ✓). Состояние — `localStorage` (`customdev-course:v1` → `{ checked: { [stageId]: [индексы] } }`).
- Все пункты отмечены → короткая вспышка ✓ (≤ 600 мс, scale/opacity), тост «С2 пройден — точка на маршруте отмечена»,
  точка на полосе плавно заливается. Reduced-motion — только смена состояния и текст.
- «Сбросить отметки» — на карте (в блоке «Как пользоваться картой») и в полосе (меню точки «…» не нужно — простая ссылка
  на карте достаточно; решение исполнителя).
- В конце Д1 — статичная карточка «Маршрут пройден»: коды всех шагов, «≈ 52 мин роликов», ссылка на карту.
  Когда отмечена самопроверка Д1 — карточка проигрывает щелчок и показывает «Все шаги отмечены», если отмечены все.

### Блок «Как пользоваться картой» (A, B)

Порядок: заголовок → плеер ролика (без autoplay, постер, субтитры, текстовая версия) → пять карточек.
Полоса в заголовке блока остаётся и получает подписи словами (B); она статичная (без «вы здесь») и объясняет
легенду липкой полосы: под словами — «точка = гайд, заливка = пройден». Решение исполнителя: так две линии
не спорят — одна легенда, одна индикатор.

### «С4·в» (дефект)

Круг кода на карте (`.course-map__no`) для длинного кода `С4·вступление` становится «пилюлей»: ширина по тексту,
высота та же, код показывается коротко «С4·вст» (полное — в `title` и тексте строки). Проверка: ни один код не
выходит за фигуру на 1440 и 390.

### Фон под меню и подпись H1

На `course/guides/` полоса другого оттенка под меню — это фон hero/атмосферы с отличающимся цветом; выровнять фон
страницы под меню с `--customdev-page-bg`. `.eyebrow` → как на главной CustomDev: `font-weight: 800`,
цвет `--customdev-green`, без моноширинного серого.

## Проверка

- Юнит: данные маршрута (порядок, ветки, суммы секунд), хранилище отметок (повреждённый JSON → пусто), состояния точек.
- Браузер (agent-browser): 1440 и 390, светлая/тёмная схема, reduced-motion, прокрутка (полоса не дёргается,
  шестерёнки вращаются только при прокрутке), якоря не уходят под полосу, щелчок на С2 и итог на Д1, сброс.
- Кадры целиком; любой видимый дефект блокирует PASS. Ревью Opus; затем Fable с отдельной проверкой понятности линии.

## Решения исполнителя по проверке дизайна (15.10)

- **Сумма времени** считается из манифестов, не вписывается числом: все шаги `route` + обе ветки С4а и С4б («можно оба»),
  без П3+ (дополнительный ролик). «Осталось» = сумма не пройденных шагов по тому же правилу. «≈ 52 мин» в тексте 008 —
  ориентир; на странице показывается вычисленное число.
- **Пройдено (вид)** = все шаги до текущего по порядку `route` (для С4а/С4б — до С4 включительно; вторая ветка не
  считается пройденной) + шаги с полностью отмеченной самопроверкой (`localStorage`). «Самый дальний шаг» не хранится.
- **«Все шаги отмечены»** на Д1 — строго: самопроверка отмечена у каждого шага `route` и хотя бы у одной ветки С4а/С4б.
- **Где полоса**: карта `guides/index.html` и страницы, чей `data-stage` — шаг `route` или ветка; на прочих (пример,
  метарепозиторий, `s4-product.html`, если её `data-stage` вне маршрута) полосы нет. Полоса не зависит от
  `data-no-motion`/reduced-motion: монтируется всегда, без движения при reduced-motion; шестерёнки — только с движением.
- **Без скачка**: сборка ставит на страницу `data-course-route` и JSON; CSS по этому атрибуту заранее увеличивает
  `--site-nav-reserve` на высоту полосы, рантайм только наполняет её.
- **Превью и значок «▶ m:ss»** — только у карточек, где ролик опубликован (существующий механизм `revealCourseMapFilm`,
  `li[data-film]` без `hidden`); путь mp4 — из ссылки ролика. Минуты в полосе — из манифестов, даже без mp4.
- **Короткие ярлыки групп** для полосы: «Подготовка», «Практика», «Разработка»; заголовки карты не меняются.
