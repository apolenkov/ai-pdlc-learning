# pages-output-safety Specification

## Purpose
Требования к безопасности каталога результата сборки: физическая проверка пути до рекурсивного удаления и записи, без следования symlink.

## Requirements

### Requirement: Validate output before recursive deletion

Сборщик SHALL до рекурсивного удаления или создания output проверить, что путь
является строгим физическим потомком разрешённого dist/, .cache/ или системного
временного каталога. Существующие компоненты между output и доверенной границей
SHALL NOT быть symlink, включая конечный компонент. Отсутствующие компоненты SHALL
разрешаться через ближайшего существующего родителя. Ошибки файловой системы,
кроме отсутствующего компонента, SHALL прекращать операцию.

#### Scenario: Parent symlink points at an external directory

- **GIVEN** синтетический внешний каталог site содержит marker.txt, а разрешённый
  output проходит через родительский symlink на этот каталог
- **WHEN** вызывается настоящий сборщик
- **THEN** сборщик отклоняет output до удаления или записи
- **AND** marker.txt сохраняет исходное содержимое

#### Scenario: Create a new directory under an allowed physical root

- **GIVEN** разрешённый output не существует и его существующие компоненты не symlink
- **WHEN** проверяется output
- **THEN** проверка допускает строгий физически вложенный путь

Проверка выполняется перед операцией; атомарная защита от конкурентной подмены
родителей между проверкой и удалением не входит в TASK-519.
