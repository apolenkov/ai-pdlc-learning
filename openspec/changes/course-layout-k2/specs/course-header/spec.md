### Requirement: Переходы и подсказки в учебном маршруте

Курс ДОЛЖЕН (SHALL) сохранять порядок переходов между уроками и показывать подсказку о подготовке отдельно от ссылки назад.

#### Scenario: Ученик открывает шаг 1 курса о намерении

- **WHEN** ученик читает карточку, а затем открывает урок
- **THEN** карточка называет подготовку по Git и две необязательные части, а обе ссылки назад в уроке ведут на четвёртую подготовку

### Requirement: Вёрстка учебных примеров при 1440 px
