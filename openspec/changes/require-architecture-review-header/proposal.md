## Why

Пакет P8, часть 2, требует явного решения о подключении архитектора к изменению.
Сейчас шаблон спецификации не фиксирует это решение, а проверка стандарта
проверяет только наличие файлов и согласованность версии.
Основание: `P8-codex-brief.md`, раздел «ЧАСТЬ 2», в передаче `feedback-1610`.

## What Changes

- Добавить обязательное поле «Архитектурный разбор» в шапку шаблона спецификации.
- Проверять наличие единственного поля и допустимость значения через штатный
  CLI `validate`, с регрессионной проверкой на изменённой копии стандарта.
- Уточнить приглашение архитектора через `@` в MR по признаку и путь `design.md`:
  ветка архитектора от ветки изменения, MR обратно в ветку изменения,
  одобрение аналитиком соответствия решения требованиям.

## Impact

Изменяются шаблон, проверка и README эталонного стандарта.
Видео, корпоративные репозитории, настройки платформы и обязательные роли
ревью остаются вне этого изменения. Проверка шаблона не заменяет ревью
заполненных спецификаций и не проверяет доступность ссылок на решения.
