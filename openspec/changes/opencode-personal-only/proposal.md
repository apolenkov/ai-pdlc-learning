## Why

Слова владельца: «OpenCode надо в учении написать, что это для личных компьютеров, а не домены.» Сейчас курс предлагает OpenCode и WSL в заявке на корпоративную Windows или VDI.

## What Changes

- На доменной Windows и в VDI ученик работает с моделью только через Kilo Code в VS Code. Из инструкции по установке и шаблона заявки исчезают OpenCode и нужный для него WSL.
- На личном компьютере с macOS или Linux ученик может выбрать OpenCode. Ограничение видно до раскрытия инструкций, в том числе на шагах курса.

## Capabilities

### New Capabilities

- `learner-tool-route` — выбор инструмента для работы с моделью по типу компьютера.

## Impact

Меняются карточка установки, карта курса, подсказки в гайдах, стандарт анализа и тесты этих материалов.
