## Why

Владелец показывает курс и учебные репозитории как свою работу. 22.11.2026 корпоративные GitLab, GHE и
сайт курса перестали быть доступны, а курс ссылается на них. Решение владельца и суперагента
(TASK-923, doc-591): курс выходит публичным репозиторием `github.com/apolenkov/ai-pdlc-learning` с сайтом на
GitHub Pages. Решение владельца 23.11.2026: публичный курс называется AI PDLC Learning, заголовки страниц
заканчиваются на «· AI PDLC Learning», учебные репозитории — `ai-pdlc-learning-stage-*`. Имя CustomDev остаётся
там, где речь о внутреннем сайте, и в кадрах уже смонтированных роликов. Исключение — карта зрелости анализа:
выгрузка навыка дорожной карты из customdev со своим заголовком «Карта зрелости анализа в PDLC», руками её не правят.
Кроме имени скрываются адреса, почта и люди.
Курс публикуется одним коммитом-снимком, а история остаётся в приватном оригинале.

## What Changes

- Ссылки на корпоративные GitLab, GHE, GHE Pages и сайт курса ведут на
  `github.com/apolenkov/<репозиторий>` и `apolenkov.github.io/ai-pdlc-learning/`. Merge request становится
  pull, pipeline — actions. Прочие корпоративные хосты и адреса почты заменяются зарезервированными
  `*.example.invalid`. Тесты с прежними адресами получают новый адрес как положительное ожидание, а старый
  хост остаётся отрицательным примером.
- Сайт собирает и выкладывает GitHub Actions (`.github/workflows/pages.yml`, `npm run build:site`). Корень сайта —
  карта курса. `.gitlab-ci.yml`, зеркало на GHE и его команда из публичной версии убираются.
- Ролики лежат в GitHub Release нового репозитория. Манифесты ссылаются на файлы релиза с прежними sha256.
  `fetch-guide-video` скачивает их без авторизации. Ненайденные мастера помечены недоступными.
- Из открытого издания 19.11 переносятся отдельными коммитами `corp-guard` и его тесты: корпоративные хосты,
  почта и имена из списка не попадают в коммит.
- Снимки экрана с идентификаторами корпоративных проектов заменяются заглушкой. Пары PNG и WebP меняются вместе.

## Impact

Меняются страницы и данные `docs/pages/sdlc-development/`, стандарт, манифесты роликов, скрипты сборки и
публикации, README, AGENTS.md, `docs/BOUNDARIES.md`. Учебные репозитории публикуются отдельно (TASK-923).
Видимость репозитория меняется только после «ок» владельца.
