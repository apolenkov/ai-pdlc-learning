## ADDED Requirements

### Requirement: Шапки и маршрут курса при ширине 1440 px

На ширине 1440 px курс ДОЛЖЕН (SHALL) показывать один текущий кружок и название шага в том же ряду. В шапке каждого курса и четвёртой подготовки виден результат обучения.

#### Scenario: Ученик открывает раздел подготовки по Git

- **WHEN** ученик переходит из оглавления или другого урока
- **THEN** номер в ссылке, ID раздела и видимый номер совпадают для всех 14 разделов

#### Scenario: Повторная приёмка страницы при ширине 1440 px

- **WHEN** проверяющий открывает страницу по тегу пакета K-1 задачи TASK-904
- **THEN** шапка, подсказки и элементы управления соответствуют критерию тега либо отчёт указывает противоречащее ему требование курса
