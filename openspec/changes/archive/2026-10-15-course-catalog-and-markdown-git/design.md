## Context

Главная уже использует общие цвета, шрифты и навигацию. course-names.json задаёт 9 шагов, 2 ветви и дополнительный П3+. terms.json нормализует термины речи; это не источник названий, целей или аудитории.

## Decisions

Сохранить оформление. После вводного текста — навигация по странице и открытый каталог строк по трём существующим группам, затем сравнение и справки. На телефоне код и длительность стоят над текстом; сравнение складывается по критериям. Использовать имеющиеся escapeHtml, filmDuration, formatDuration и mapping манифестов; вставлять каталог при сборке, включая offline ZIP. MP4 не обязателен для каталога. Нет фильтрации и дополнительного browser JS.

Названия/коды/ссылки — course-names.json; длительности — FILM_MANIFESTS (П2 имеет существующий fallback к последней главе). goal — переформулировка gain и экранных GOALS из video/_shared/tools/build-map.mjs; audience — роли/контекст из guides/guide-stages.ts. Источники возможностей Confluence/GitLab — официальная документация, ссылки в разделе главной.

## Validation

До изменения сборки новый тест вывода главной падает: 0 вместо 12. После — все 12 доступны, включая П3+ и ветви, даже без MP4. npm test, npm run typecheck, npm run build:site. Agent-browser: 1440/390, полный просмотр страницы, все ссылки/якоря, отсутствие горизонтальной прокрутки, keyboard/focus. Три независимых read-only design-pass и отдельное Astra review готового diff.
