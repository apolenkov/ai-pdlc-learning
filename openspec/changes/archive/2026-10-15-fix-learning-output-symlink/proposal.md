# Безопасный каталог результата сборки

## Why

Проверка строкового вложения PAGES_OUTPUT_DIR не исключает symlink в родительском
каталоге. Рекурсивное удаление может затронуть внешний каталог до сборки сайта.

## What Changes

- Перед удалением проверяются существующие компоненты пути через lstat и физическое
  вложение в разрешённый каталог по готовому шаблону CustomDev.
- Проверка становится асинхронной; сборщик, CLI и существующие assertions ожидают её.
- Изолированная регрессия вызывает настоящий сборщик с symlink и проверяет сохранность
  синтетического внешнего маркера. Новые отсутствующие каталоги остаются допустимыми.

## Impact

Backlog: TASK-519, координатор wrk-42; источник риска — оценка TASK-515.
Меняются только проверка output и её tests; маршруты сайта, входные данные и набор
артефактов сохраняются. Тесты, сборка и push ждут явного разрешения wrk-42 после HOLD.
