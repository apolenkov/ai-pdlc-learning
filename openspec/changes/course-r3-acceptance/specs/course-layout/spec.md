## ADDED Requirements

### Requirement: Чтение гайда

Курс ДОЛЖЕН (SHALL) показывать всё оглавление, ссылки на существующие шаги, главы видео на всю ширину списка и одну подпись каждого варианта. Свёрнутые блоки помощи и дополнений оформлены одинаково.

#### Scenario: Ученик открывает инструкцию при ширине 1440 px

- **WHEN** ученик читает подготовку по Git
- **THEN** видны все 14 пунктов оглавления без внутренней прокрутки, заголовок первого шага находится в пределах двух экранов

#### Scenario: Ученик выбирает материал

- **WHEN** ученик открывает первый шаг урока о требованиях в Git или о контексте продукта
- **THEN** ссылки на пример и скачивание с названием файла помещаются в один ряд при 1440 px

### Requirement: Полоса маршрута и страницы курса

Курс ДОЛЖЕН (SHALL) показывать название урока и время роликов без обрезки, отличать пройденную самопроверку знаком, объяснять дополнительную карточку подготовки и сохранять читаемость заголовка калькулятора под меню.

#### Scenario: Ученик возвращается к уроку

- **WHEN** ученик полностью выполнил самопроверку
- **THEN** знак на полосе отличает этот урок от предыдущего по порядку при повторном открытии страницы

#### Scenario: Ученик переходит к калькулятору по якорю

- **WHEN** заголовок сценария оказывается под верхней панелью
- **THEN** фон и тень панели не перекрывают текст под ней
