# AGENTS.md

Репозиторий содержит исходники курса «Анализ с ИИ-агентами» для людей и ИИ-агентов. Правки вносите через pull request.

## Границы

- Добавляйте только учебные материалы курса, гайды, примеры, медиа и стандарт аналитика. [Границы репозитория](docs/BOUNDARIES.md).
- Не добавляйте пароли, токены, ключи, персональные данные сотрудников, внутренние выгрузки и карты команд, корпоративные навыки и материалы закрытых проектов.
- В примерах используйте только вымышленные имена. Закрывайте реальные адреса и учётные данные на скриншотах.
- Решение о лицензии принимает владелец. Не добавляйте и не меняйте лицензию.
- Не правьте `dist/` вручную и не коммитьте его. Не коммитьте mp4 и рендеры.

## Работа в репозитории

[Структура и источники, команды, worktree и навыки OpenSpec](docs/REPO-GUIDE.md).

Цель, состояние и план ведите в личном Backlog (`~/work/backlog`, CLI `backlog`), требования и сценарии — в OpenSpec (`openspec/`). Связывайте карточку и change ссылками.

Перед завершением запустите `npm test` и `npm run typecheck`. Не обходите хуки Git (`lefthook`).

## Правила изменений

- Используйте Conventional Commits с областями `course`, `guides`, `examples`, `standards`, `skills`, `site`, `scripts`, `docs`, `repo`, `ci`, `deps`.
- Сверяйте зависимости, Node, npm и образы CI с реестром на дату правки и используйте последние стабильные версии.
- Меняйте скриншот `*.png` вместе с `*-600.webp` и `*-1200.webp`. Для скрытого снимка оставляйте файл-заглушку.
- Один файл в одном pull request правит один автор. Параллельные изменения файла согласуйте в обсуждении.
- Проверяйте каждую правку сайта на 1440, 1024 и 390 px. Смотрите кадр целиком, включая мобильное меню и полосу маршрута (TASK-562). Видимый дефект (обрезка, наложение, нечитаемый контраст) блокирует приёмку, в том числе на 390 px.
- Соблюдайте [правила оформления курса и стандарта](docs/COURSE-RULES.md). Подавайте интерфейс и терминал парами. Пишите термины латиницей, без кодов шагов и слова «отметки». Название команды — «Команда развития процессов AI PDLC». Эти правила на всех страницах проверяет `npm test`.

Исходники курса — [на GitHub](https://github.com/apolenkov/ai-pdlc-learning). Workflow `.github/workflows/pages.yml` собирает сайт и публикует его [на GitHub Pages](https://apolenkov.github.io/ai-pdlc-learning/).
