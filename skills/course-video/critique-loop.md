# Самокритика кадров до независимого ревью

Цель: Astra/Opus получают сцены, где очевидное уже исправлено. Работает на контактных листах (`node tools/scene.mjs N snapshot --at …`), полный кадр — только на подозрительное место.

1. Оценка по 8 критериям, каждый 0–2 (всего 16): смысл (кадр объясняет фразу), фокус (первый взгляд — на главном), ритм (темп под речь, без дубля), оригинальность (нет запретов из `motion-rules.md`), бренд (токены, шрифты, один акцент), читаемость (≥28 px, AA, субтитры не закрыты), целостность (нет обрезки, наложения, пустого кадра), согласованность (текст = речь = страница).
2. Порог: сцена ≥14 из 16 и ни одного критерия 0. Иначе правка и повторный лист (не больше 3 кругов; после третьего — вопрос координатору с рекомендацией).
3. Оценивает Haiku-разведчик (`haiku-scout`) по листу и брифу, возвращает таблицу «сцена, критерий, балл, одна фраза причины»; правит автор сцены. Автор свою оценку не выставляет.
4. Протокол — в `film/critique/scene-NN.md` (баллы по кругам). Любой видимый дефект кадра блокирует PASS независимо от баллов.
5. Только после порога сцены идут к Astra (`opus-reviewer` — резерв).
