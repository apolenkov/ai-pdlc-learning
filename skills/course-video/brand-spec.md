# Бренд и спецификация роликов курса («Студия», вариант B)

Один источник на все сцены и ролики: `video/<block>/film/kit/tokens.css` (правка стиля = правка только этого файла; kit — `video/block-0/film/kit/`, копия в block-0a). Здесь — выжимка, чтобы не вычитывать файл.

| Что | Значение |
| --- | --- |
| Кадр | 1920×1080, 30 fps; шапка y 20–106, контент от y 200 до ≈865, ниже — субтитры (bottom ≥ 130 px) |
| Фон | `--k-bg #0f1115`, сетка `--k-grid`, тёплое свечение `--k-glow` |
| Текст | основной `--k-text #eef0f3`, вторичный `--k-text-2 #a3a9b4`; минимум 28 px, контраст AA |
| Акцент | коралловый `--k-accent #ff7a59` (+ `--k-accent-soft #ffb59f`, `--k-accent-tint`); один акцент на кадр |
| Статусы | готово/проверено `--k-ok #3ccf91`; справка `--k-info #7cc4ff` |
| Панели | `--k-panel #171a21`, `--k-panel-2 #1d212a`, линия `--k-line #2a2f3a`; радиусы окно 22, карточка 24, плитка 22 |
| Шрифты | Inter (текст), JetBrains Mono Local (код, пути, команды); других нет; `monospace` и `Menlo` запрещены |
| Размеры | шапка 30, часть 38, подпись 30, текст 32, субтитры 42, код 30, цель 46 (px) |
| Движение | вход 0,7 с `power3.out`, выход 0,55 с `power2.in`, pop 0,6 с `back.out(2)`, камера 1,2 с; blur 14 px, масштаб 0,95↔1,05 между планами |
| Скетчи | векторные люди одним контуром: белая линия `#eef0f3` на тёмном, один коралловый акцент, без карикатурности, `viewBox 640×480`, исходники `assets/sketches/*.svg`, сборка `tools/build-sketches.mjs`; скетч показывает действие, карточка рядом — результат (подпись не дублируется) |
| Названия | команда — `TEAM_NAME` из `docs/pages/sdlc-development/course-names.json`, в речь и кадр не вшивать; заставки — `tools/build-titles.mjs` |

Сайт курса (светлый, `learning-enhancements.css`) в ролике не копируется: ролик тёмный, но термины, названия частей и подписи совпадают со страницами.
