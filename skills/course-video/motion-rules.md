# Правила движения роликов курса

Обвязка вокруг сцены: промпт даёт малую часть результата, остальное — эти правила, бренд (`brand-spec.md`), бриф сцены (`scene-brief.md`) и самокритика (`critique-loop.md`). Читать перед написанием любой сцены.

## Запреты на шаблонное (любой пункт — минус балл в самокритике)

1. Текст по центру на градиентном фоне без опоры на схему, скетч или карточку. Опора: сетка, окно, скетч, плитка из kit.
2. Одинаковое появление у всех элементов сцены (все fade-in снизу с одной задержкой). Минимум два разных вида входа по смыслу: пояснение — въезд, результат — pop, переход — blur/scale.
3. Движение без смысла: объект двигается, но зритель не должен ничего заметить. У каждого движения есть вопрос «что зритель понял от этого».
4. Слово раньше речи: элемент появляется не раньше чем за 0,3 с до слова, к которому привязан, и не позже слова (время только через `S.t("фраза")`).
5. Два одинаковых смысла в кадре: надпись, повторяющая шапку, плитку или субтитр.
6. Декор: иконки, свечение и фигуры без смысла; один акцент на кадр (коралловый), зелёный только для «готово/проверено».
7. Текст мельче 28 px, контраст ниже AA, контент ниже y≈865 (зона субтитров).

## Три правила тайминга (из навыка motion-design, D34)

- Выход короче входа на 25–35 % (вход `--k-dur-in` 0,7 с → выход ≈0,5 с).
- Не гасить значимое: пока слово ещё звучит, элемент остаётся видимым и неподвижным; гасят только то, что уже сказано.
- Тишина 100–200 мс между битами: после появления смыслового элемента — короткая неподвижность, затем следующий.

## Ритм

- Главное — один фокус за раз: что зритель должен увидеть первым — указано в брифе; остальное тише (`--k-text-2`, меньший размер) или ещё не появилось.
- Темп под речь: новый смысловой элемент не чаще одного на 2–3 с; чтение — ≥3 слов/с + 1 с (проверяет `read()` в сценах).
- Состояние «было» — тёплое и тесное (акцент-мягкий, хаос стрелок), «стало» — спокойное (одна линия, зелёный).
